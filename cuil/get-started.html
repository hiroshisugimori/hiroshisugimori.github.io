Get Started

5つの操作を試して、CUILをすぐ使えるようにしましょう。

対象実装: 0.1.83 / versionCode 94 · 最終確認: 2026-11-22

まずCUILを開いてください。ホームボタンで戻れるようにする場合は、Androidの「既定のホームアプリ」に設定します。以下の例では、登録済みのコマンドがない状態を想定します。

1. アプリ名で起動する

入力欄に、端末に入っているアプリの名前を入力してみましょう。

  1. CUILの入力欄をタップします。
  2. Chrome など、インストール済みアプリの名前の一部を入力します。
  3. 候補から目的のアプリをタップします。Enterでも選択中の候補を実行できます。
操作例（模式図）

C:\HOME> chr▌

Chrome → タップして起動

できるようになること：アプリ名の一部から目的のアプリを開く。

名前の表記が多少違っても検索できます。候補が出ない場合は、実際のアプリ名と、端末にインストール済みかを確認してください。

アプリ検索を詳しく読む →

2. 短いコマンドを登録する

よく使うアプリに、自分が覚えやすい短い名前を付けます。ここでは web を例にします。

  1. 右上の縦三点メニュー →「コマンド登録」を開きます。regist を実行しても開けます。
  2. コマンド名に web と入力します。
  3. 「アプリ」タブで目的のブラウザを探してタップします。新規登録はこのタップで完了します。
  4. トップ画面に戻り、web を入力して、登録した候補を実行します。

できるようになること：短い名前でアプリを呼び出す。

command で一覧を開き、行のメニューから編集・削除できます。編集画面の変更は保存で確定します。ショートカットやアクションにもコマンドを付けられます。

タグ・引数共有・グループも読む →

3. ジェスチャーを登録して使う

まずは丸でアプリを起動し、慣れたらタップや2本指・3本指へ進みましょう。登録できる操作は計65種類。種類ごとに別のアプリ・ショートカット・アクションを割り当てられます。

まず丸を試すダブルタップ・トンツー2本指・3本指うまく動かないとき

まずは丸に、よく使うアプリを登録

  1. トップ右上の縦三点メニュー →「設定」を開きます。
  2. 「ジェスチャー」欄で「ジェスチャーを有効にする」をオンにし、「ジェスチャー登録」を開きます。
  3. 「図形ジェスチャー」で「丸」を探します。行のガイドを見て、「登録」から端末にあるアプリを選びます。
  4. トップ画面に戻り、空白部分から丸を1本の線で描き、指を離します。

丸に割り当てたアプリが開けば成功です。次は別のジェスチャーに、別のアプリを登録してみましょう。

登録画面上部のリンクで5つのカテゴリへ移動できます。操作説明は右上の丸い「？」から開き、スクロールして読めます。「登録解除」で割り当てを外せます。

ダブルタップと「トンツー」を試す

どちらも、まず1回短くタップして指を離します。1本の指で続けて操作するもので、2本の指を同時に置く操作とは異なります。

  1. 登録画面の「ダブルタップ」で「同じ位置」にアプリを登録します。
  2. トップに戻り、同じ位置を続けて2回タップして離します。
  3. 次に「トンツー（同じ位置）」へ別のアプリを登録します。
  4. 1回短くタップして離し、すぐに同じ位置を長押しします。長押しが成立した時点で動作します。

右・左・上・下は、2回目に触れる位置です。例えば「右」は、1回目の点から右へ離れた場所を2回目にタップします。指を置いたまま右へ滑らせる操作ではありません。

ダブルタップかトンツーを登録すると、通常の1回タップも2回目の入力を待ってから実行されます。ピンチだけの登録では、この待ち時間は追加されません。

2本指・3本指を試す

まず「ピンチ／2本指」から「ピンチアウト（水平）」にアプリを登録してください。トップで2本の指を左右に置き、間隔を広げ、片方を離します。アプリが開けば成功です。次に、図を参考に別の操作を試してみましょう。

図は模式図です。丸は指を置く位置、矢印は動かす向きを表します。

2本指の使い分け

  • イン／アウト：近づけるとイン、広げるとアウト。開始時の指の並びで「右手斜め（左下↔右上）」「左手斜め（左上↔右下）」「水平」「縦」に分かれ、それぞれ別に登録できます。
  • 回転：つまみを回すように、時計回りが右回転、反時計回りが左回転。開始時の指の向きは自由です。
  • 平行移動：指の間隔を大きく変えず、2本とも同じ斜め方向へ動かします。「右手斜め下＝右下」「右手斜め上＝左上」「左手斜め下＝左下」「左手斜め上＝右上」です。

三本指の使い分け

登録画面の「三本指」から、イン・アウト・右回転・左回転を個別に登録します。インは3本を寄せ、アウトは3本を外側へ広げます。回転は時計回り／反時計回りです。

アウトでは、上側の2本を平行に斜め上へ動かし、下側の1本を下へ動かす形でも認識します。回転では、2本が十分に回転していれば、残り1本の動きが短い、またはほぼ動かない形も認識します。

2本指・3本指は、指を置く → はっきり動かす → 使っている指のうち1本を離す、の順で実行します。動作は1回だけで、残りの指を離しても重複実行しません。

うまく動かないとき

  • ジェスチャーを有効にし、試す種類に動作を割り当てているか確認します。未登録の操作は実行しません。
  • 最初は空白部分で、ガイドに沿って少し大きめにはっきり動かします。小さな指のずれだけでは実行しません。
  • 三本指アウトでは、3本それぞれを外側へ動かします。3本をそろえて同じ方向へ滑らせるだけではアウトになりません。
  • 通常のアプリ起動にユーザー補助サービスの有効化は不要です。通知欄などのシステム操作を割り当てる場合だけ、対応するサービスを有効にします。
  • トップのアイコンやボタン上からも開始できますが、よく使うアプリのスクロールや共有先ボタンのドラッグ中などには別の判定があります。まず空白部分で確認してください。

65種類すべての名前と操作方法、開始できる場所・キャンセル条件も確認できます。

4. 入力した言葉をそのまま検索する

  1. 入力欄に 週末の天気 などの検索語を入力します。
  2. 上部の検索ボタンをタップします。初期設定ではGoogle検索が開きます。
  3. 戻って別の検索語を試します。
操作例（模式図）

C:\HOME> 週末の天気

検索ボタン → Google検索

できるようになること：候補の有無にかかわらず、検索ボタンで入力を検索先へ送る。

通常の検索語で候補が1件もない場合は、明示的にEnterを押しても検索できます。候補がある場合はEnterでその候補が実行されます。日本語変換の確定だけでは検索しません。迷ったときは検索ボタンを使ってください。

既定先・Enter・URLの違いを読む →

5. 共有先を登録してテキスト・画像を送る

先に共有先を登録し、その後で送る内容を入力します。

  1. 上部の検索・投稿ボタンを長押し →「共有先を追加」を開きます。
  2. 管理画面の右下の追加ボタンを押し、普段使う共有対応アプリを探して選びます。
  3. トップへ戻り、送りたいテキストを入力します。
  4. 検索・投稿ボタンを長押しし、登録した共有先を選びます。
  5. 画像も送る場合は、テキストを入力した後、上部の＋から画像・ファイル・カメラを選んで添付し、同じ共有先へ送ります。

できるようになること：登録したアプリへテキストや画像を直接共有する。

管理画面の「ボタンを表示」で、専用の共有ボタンをトップへ追加できます。「デフォルトにする」で通常タップの行き先も変更できます。相手アプリによって受け取れる形式が異なるため、まずテキストだけ、次に画像だけで確認してください。
