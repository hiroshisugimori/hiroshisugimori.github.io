Get Started

5つの操作を試して、CUILをすぐ使えるようにしましょう。

対象実装: 0.1.64 / versionCode 75 · 最終確認: 2026-10-30

まずCUILを開いてください。ホームボタンで戻れるようにする場合は、Androidの「既定のホームアプリ」に設定します。以下の例では、登録済みのコマンドがない状態を想定します。

1. アプリ名で起動する

入力欄に、端末に入っているアプリの名前を入力してみましょう。

  1. CUILの入力欄をタップします。
  2. Chrome など、インストール済みアプリの名前の一部を入力します。
  3. 候補から目的のアプリをタップします。Enterでも選択中の候補を実行できます。
操作例（模式図）

C:\HOME> chr▌

Chrome → タップして起動

できるようになること：アプリ名の一部から目的のアプリを開く。

名前の表記が多少違っても検索できます。候補が出ない場合は、実際のアプリ名と、端末にインストール済みかを確認してください。

アプリ検索を詳しく読む →

2. 短いコマンドを登録する

よく使うアプリに、自分が覚えやすい短い名前を付けます。ここでは web を例にします。

  1. 右上の縦三点メニュー →「コマンド登録」を開きます。regist を実行しても開けます。
  2. コマンド名に web と入力します。
  3. 「アプリ」タブで目的のブラウザを探してタップします。新規登録はこのタップで完了します。
  4. トップ画面に戻り、web を入力して、登録した候補を実行します。

できるようになること：短い名前でアプリを呼び出す。

command で一覧を開き、行のメニューから編集・削除できます。編集画面の変更は保存で確定します。ショートカットやアクションにもコマンドを付けられます。

タグ・引数共有・グループも読む →

3. ジェスチャーを登録する

まずは丸に、よく使うアプリを割り当ててみましょう。

  1. 右上メニュー →「設定」→「ジェスチャー」を開きます。
  2. ジェスチャーがオフなら有効にして「ジェスチャー登録」を開きます。
  3. 「丸」の描き方ガイドを確認し、その行の「登録」からアプリを選びます。
  4. トップ画面へ戻り、空白部分から丸を1本の線で描いて指を離します。

できるようになること：丸を描いてアプリを起動する。

通常のアプリ起動にユーザー補助サービスの有効化は不要です。通知欄などのシステム操作を割り当てる場合だけ、対応するサービスが必要です。よく使うアプリ上ではスクロールとの判定があるので、初めは空白部分で試してください。

全22種類と判定条件を読む →

4. 入力した言葉をそのまま検索する

  1. 入力欄に 週末の天気 などの検索語を入力します。
  2. 上部の検索ボタンをタップします。初期設定ではGoogle検索が開きます。
  3. 戻って別の検索語を試します。
操作例（模式図）

C:\HOME> 週末の天気

検索ボタン → Google検索

できるようになること：候補の有無にかかわらず、検索ボタンで入力を検索先へ送る。

通常の検索語で候補が1件もない場合は、明示的にEnterを押しても検索できます。候補がある場合はEnterでその候補が実行されます。日本語変換の確定だけでは検索しません。迷ったときは検索ボタンを使ってください。

既定先・Enter・URLの違いを読む →

5. 共有先を登録してテキスト・画像を送る

先に共有先を登録し、その後で送る内容を入力します。

  1. 上部の検索・投稿ボタンを長押し →「共有先を追加」を開きます。
  2. 管理画面の右下の追加ボタンを押し、普段使う共有対応アプリを探して選びます。
  3. トップへ戻り、送りたいテキストを入力します。
  4. 検索・投稿ボタンを長押しし、登録した共有先を選びます。
  5. 画像も送る場合は、テキストを入力した後、上部の＋から画像・ファイル・カメラを選んで添付し、同じ共有先へ送ります。

できるようになること：登録したアプリへテキストや画像を直接共有する。

管理画面の「ボタンを表示」で、専用の共有ボタンをトップへ追加できます。「デフォルトにする」で通常タップの行き先も変更できます。相手アプリによって受け取れる形式が異なるため、まずテキストだけ、次に画像だけで確認してください。
