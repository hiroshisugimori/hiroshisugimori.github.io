Home and basic navigation

CUIL is a home app for Android 16 or later. Select it as your default Home app in Android settings to return to it with Home. The top-right menu opens Settings, command registration and lists, App list, the right screen, Text snippets and Drafts.

  • Type in the command field and tap a suggestion. Enter runs the selected suggestion, normally the first one.
  • Tap an empty area to focus the input and show the keyboard. Use the microphone for voice input.
  • Swipe up to open App list. Upward swipes starting in frequently used apps are excluded. A straight leftward swipe from the right edge opens the right screen.
  • Open Settings → Launcher → AOSP Launcher3 settings for the underlying launcher options.
  • Long-press an empty area for registration, settings, clear, history, wallpaper and related commands.

Appearance and the keyboard’s execution key vary by theme and device.

App search and suggestions

Type an app name to see suggestions. App names are matched across hiragana/katakana, full-/half-width alphanumeric characters, letter case, and the presence of ordinary spaces. Tap to launch; long-press for available actions such as app information, shortcuts and sharing.

The Prefix/Contains option in Settings controls command matching. The input combines apps, registered commands and built-ins. Availability of apps in other profiles depends on the device and profile state.

Enter can execute a partial-match suggestion rather than the literal text alone. Check and tap the desired suggestion when choosing a specific app.

Registering commands, tags and groups

  1. Open Register command from the top-right menu, or run regist.
  2. Enter a command name and choose Apps, Shortcuts or Actions.
  3. For a new app/shortcut registration, tapping the target completes registration. Some actions require an additional input and confirmation.
  4. Run command to open the list. Tap a row for Run, edit, delete and other available operations. Save confirms edits.

Details contains tags, argument sharing and fixed-text sharing. Tags appear as #tag1 #tag2 and can narrow suggestions. With Share arguments enabled for an app/shortcut, a command such as note Today’s memo passes the remaining text to its target. Fixed-text sharing sends the text saved at registration. These options are mutually exclusive.

Names such as work/mail and work/map form a group. Selecting one from input without a slash first completes work/; then choose the command inside the group. Avoid names that conflict with built-ins.

Gesture assignments: all 22 shapes

Enable gestures in Settings → Gestures, then open Gesture assignments. Choose Register for a shape and assign an app, shortcut or action. Each row provides a drawing guide; Remove assignment clears it.

Drawing an unassigned shape does not launch an app. The upward swipe for App list is separate from assignable shapes.

Gesture starting areas and recognition

  • Start in an empty area, the header/input, search, attachment, microphone or menu controls, or bottom function keys and their gaps. Distinguish drawing from normal taps and long presses.
  • On additional sharing buttons, use a quick stroke for a gesture; a long press starts button repositioning.
  • If frequently used apps do not scroll, finger movement starts gesture drawing immediately.
  • In a scrollable area, scrolling has priority until horizontal movement exceeds one quarter of the screen width, or the finger leaves the area in a non-upward direction. Leaving through the top alone does not switch to drawing.
  • Upward swipes starting on frequently used apps do not open App list.
  • The app-list swipe needs at least 16dp of upward travel, within 25 degrees either side. Assignable up-diagonal lines need 48dp of vertical travel, down-diagonals 96dp, and a straight down stroke 56dp.
  • U and arch matches take priority over circles. Endpoint gaps, reversals and curvature also affect recognition. Follow the guides and draw each shape in one continuous stroke.

Bottom function keys

Ten fixed buttons use two rows: F6–F10 above F1–F5. Tap to run an assignment and long-press to change it. Choose apps, shortcuts or actions in the assignment screen.

Default candidates for F1–F5 are Phone, Messages, Maps, Chrome and Camera. Availability depends on installed apps. Gestures can also start on these buttons.

Search and direct web/email input

Enter a query and tap the top search button to send it to the default search/sharing destination; the initial default is Google Search. Explicit Enter also searches ordinary text with no matching suggestion. When an app or command matches, Enter runs that suggestion instead.

IME composition confirmation, or a cursor/selection change alone, does not start a search. Merely typing a word does not search automatically.

Execute a URL such as https://example.com/, a web address or an email address directly to open its browser/email handler. Directly opened addresses are recorded in command history. chrome:// is not supported for direct execution or URL registration.

Sharing destinations

  1. Long-press the top search/post button and choose Add sharing destination. Settings → Edit post button long-press menu opens the same management screen.
  2. Use the bottom-right Add button and choose an app or an available shortcut. The app filter uses prefix matching with Japanese script, width and case normalization.
  3. Send your entered text and attachments to the registered destination.

Google Search, YouTube Search and Maps Search are included initially. Google cannot be removed or disabled. YouTube and Maps can be enabled/disabled; added destinations can be deleted.

Choose Set as default from a destination’s three-dot menu to change the main search button. A green check marks the default. Deleting or disabling it restores Google Search as the default.

Being listed does not guarantee an app can receive all text, images or multiple files. The receiving app determines what it accepts. Search services may not accept attachments.

Sharing buttons and placement

Choose Show share button in destination management to add a direct sharing button to Home. Long-press and drag an added button within CUIL Home; its position is saved. Hiding it or making its destination the default resets that position.

New buttons start below the default button. After a column of four, other available positions near the attachment button are used. The main button’s long-press menu lists other enabled destinations and Add sharing destination.

Attachments, voice input and clearing

Use + to attach camera images, selected images or files. Remove an attachment with × next to its name. Settings → Show attachment button controls whether + is visible.

When both text and files are present, CUIL sends them together to compatible destinations. Frequently used apps hide while files are attached. Returning from a picker or camera preserves the input and attachments.

The top command field is not a persistent draft. Execution, sharing/search and returning Home can clear it. Attachments are removed by execution or ×. If a clear happens just before a share-button action, CUIL temporarily retains the payload for that action and discards it after launch succeeds or on return. Use Drafts for text you want to keep.

The microphone starts/stops voice input. Microphone permission and a recognition service are required; processing and network behavior depend on that service.

Frequently used apps

CUIL ranks apps using the latest 200 launches from command input and frequently used apps. Aliases/arguments for the same app are combined. Defaults are Icons and 10 apps.

  • Choose List/Icons and None, 4, 5, 6, 7, 10 or 15 apps in Settings. Icons use five per row, with More sharing a full final row.
  • Tap to launch. The first long-press menu item excludes an app. Remove it from the hidden list in Settings to count future launches again.
  • More opens the unlimited list. Settings can reset the counts.
  • Typing or attaching files hides this area. Deleting the text alone does not restore it; returning Home, clearing, or returning from Settings restores it when appropriate.

Counts and exclusions are not included in CUIL Drive backups.

Text snippets

Open the snippet list with memo or the top-right menu. Add an optional title and multiline body with +, then Save. There is no fixed item-count limit. Rows preview up to two lines and offer copy, share, edit and delete.

Type memo with a space for numbered suggestions in list order. Untitled entries use a shortened body. Select one or run memo 1 to copy the full body. With no saved snippets, the memo command remains available. The list closes after copy/share. Snippets are included in backups.

Drafts

Use underwrite to create a draft. The body autosaves and supports attachments, voice input and sharing. Attached files appear at the bottom with names and removal buttons.

Share offers registered destinations including Google Search, All apps (Android’s share sheet), and Add sharing destination. The menu opens Drafts or Text snippets; copying a snippet returns to the draft you were editing.

lastunderwrite opens the most recently saved/updated draft, or creates a new one if none exists. Reopen and delete drafts from the list. Draft bodies and copied attachments stay on the device and are excluded from CUIL Drive backups.

Command history and search history

history contains command execution and directly opened URLs, with timestamps. Run entries again or use their menus to delete/add to favorites. A directly opened URL is added as an unnamed URL action.

searchhistory is separate and records queries, destinations and execution time from the search/post feature, newest first. Tap to repeat with the same destination; long-press to choose another registered destination or delete the entry. Clear all asks for confirmation.

Choose 10, 50, 100 or 1000 entries for each history in Settings; the default is 50, dropping oldest entries first. Command history is optional in backups. Search-history entries are not backed up.

Favorites and folders

Open with favorites, the menu or an assigned action. Add apps, shortcuts and actions, and organize them in folders. Drag to reorder or move into folders; item menus provide deletion and other actions. Rename/delete folders and move items to their parent folder. Removing a favorite does not uninstall its app.

Boxes

Run box and enter a name, or use box Work. CUIL opens the matching Box or creates it. Add apps, shortcuts and actions with + and switch Boxes from the title.

Long-press and drag to reposition items. Dropping into the removal area removes only the Box entry. The menu creates, renames, resizes and deletes Boxes. Rows and columns each range from 1–16; items hidden by shrinking are retained. Choose a separate Box theme in Settings. Box data is backed up.

Header and appearance

Settings → Appearance controls the Terminal theme, Box theme, CUIL wallpapers and the normal home/lock-screen wallpaper picker. Themes include DOS, Ubuntu-style, Green, Amber, Blue Screen and Neon. CUIL wallpapers support multiple images, time windows and a minimum display duration.

Header settings or edit-headliner edits the title, battery, date/time, memory usage, available storage, days until a selected date and a memo. Mem. is used/total memory; Str. is available storage. GB uses 1024³ bytes with two decimal places.

The title is shortened to one line and additional information wraps; its row collapses when empty. Deadlines use dates only: the date itself is 0 days remaining, and later dates are marked overdue. Save enables only when values change and disables if reverted. Leaving without saving does not apply edits.

QR codes, OCR and clipboard

qrmake follows text input → Create → preview → Share. It shares a PNG and closes the preview after launching sharing. Empty or oversized input cannot be encoded.

img2text opens image recognition from a file or camera using Google ML Kit. clip2doc saves clipboard text under Documents; follow the prompts for destination and filename.

Clipboard reads/copies occur when you invoke their corresponding features. Android pickers provide image/file access and save destinations.

Calculator, speech and other tools

calc switches to a calculator. Enter an expression or use its buttons; EXIT or Esc returns. say text to read speaks text; sayconfig configures language, voice, rate and pitch.

battery, date, unixtime, version, memory, storage, uptime and locale show information. beep plays a tone, clear clears the log, and help opens the built-in list.

gameover shows a special screen and lifegame runs Conway’s Game of Life. Tap or enter input to leave Life mode.

Deleting screenshots

Run delete-screenshots and grant access to Pictures/Screenshots through Android’s folder picker. Choose all images or those at least 1, 7 or 30 days old, review the count and confirm.

Ages use 24-hour periods from processing start. Capture time is preferred, then addition time, then modification time. Unknown dates are excluded from age-limited deletion. Only images directly in the selected folder are targeted.

Deletion is permanent. After CUIL’s confirmation, it deletes using the saved folder grant without a per-file OS confirmation. Notifications report progress/results. Keep copies of important images beforehand.

Backup and restore

Open Settings → Backup and restore, choose a Google Account and save to Drive with a name. Multiple named backups are supported; overwriting a name and restoring require confirmation. Choose a backup to replace supported settings. Backups are not automatic.

CategoryData
IncludedTerminal/Box themes, command search mode, header settings, gesture enablement/assignments, registered commands/tags, function-key/dock assignments, snippets, favorites, Boxes and history-limit settings.
OptionalCommand history. Restoring a backup that omits it preserves current command history.
ExcludedDrafts/attachments, search-history entries, sharing destinations/default/button positions, wallpaper images/settings, frequent-app counts/display settings, hidden apps, other unsupported preferences such as voice settings, purchases, Google credentials, workspace/widgets and folder grants.

Backups use CUIL’s private Drive app folder, not the ordinary file list. On another device, contacts, files, shortcuts and similar references may require reselection. Google Play manages purchases; Android manages permissions. Read the data deletion instructions.

Permissions and the accessibility service

Open notifications, Quick Settings and Power menu use “CUIL system controls,” enabled in Android Accessibility settings. If disabled, attempting an action explains the feature and provides a route to settings.

Use is optional and other features remain available. This service acts only when you request the corresponding operation. It does not read screen content, typed text or notification contents, or collect accessibility events. Disable it at any time in Android settings.

Voice input, camera, selected images/files/contacts and Drive authentication use their respective permission or picker flows. External services and advertising SDKs have separate data practices: read the privacy policy.

Settings, release history and ads

Open Settings with cuilsetting or the menu. It contains Appearance, frequent apps, history limits, search mode, sharing destinations, attachment-button visibility, gestures, backups, Launcher3 settings, version information, release history, privacy policy and terms.

Settings shows all release notes, newest first. Startup shows up to three new entries and does not repeat them for an acknowledged version. Acknowledgment state is not included in Drive backups.

The free app displays ads. Settings offers an ad-removal purchase and purchase checks through Google Play. Use the purchasing Google Account to restore access. Confirm prices in the purchase screen.

Troubleshooting

Enter opens an app instead of searching
Matching suggestions take priority. Use the search button to send the query to the default destination.
Confirming Japanese input does not search
Composition confirmation alone does not search. Use an explicit execution key or the search button.
An added destination does not receive images
Check supported formats, multiple attachments and text/image combinations. Try a single image or text alone.
Upward swipes on frequently used apps do nothing
That area does not trigger App list. Start from an empty area or use App list in the menu.
A gesture does not run
Check enablement, assignment, guide shape, starting area and scrolling rules.
A system action does not open
Check CUIL system controls in Accessibility settings and device support.
Restored entries fail or wallpapers are missing
Some references require reselection; some data is excluded. Check the backup table.

For support, include your app version, device/Android version and reproduction steps. Do not send credentials, personal information or backup files.
