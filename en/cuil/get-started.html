Get Started

Try five actions and start using CUIL right away.

Open CUIL first. Set it as the default Home app in Android settings if you want Home to return to it. Examples assume no conflicting custom commands.

1. Launch an app by name

Try the name of an app installed on your device.

  1. Tap CUIL’s input field.
  2. Type part of a name, such as Chrome if it is installed.
  3. Tap the app suggestion. Enter can also run the selected suggestion.
Illustrative example

C:\HOME> chr▌

Chrome → tap to launch

You can now launch an app from part of its name.

If nothing matches, check the actual app name and whether it is installed.

2. Register a short command

Give a frequently used app a short name you can remember. This example uses web.

  1. Open the top-right menu → Register command, or run regist.
  2. Enter web as the command name.
  3. In Apps, find and tap your browser. Tapping the target completes a new registration.
  4. Return to Home, type web and run the registered suggestion.

You can now launch an app with your own short name.

Run command to edit or delete a registration through its row menu. Save confirms edits. Commands can also target shortcuts and actions.

3. Assign and use gestures

Start by launching an app with a circle. Then try taps and two- or three-finger gestures. There are 65 assignable gestures, each with its own app, shortcut or action.

Start with a circleDouble tap / tap and holdTwo / three fingersTroubleshooting

Assign an app to Circle

  1. Open the top-right three-dot menu → Settings.
  2. In Gestures, turn on Enable gestures and open Gesture assignments.
  3. Find Circle under Shape gestures. Check its guide, choose Register, and select an installed app.
  4. Return Home, draw one continuous circle starting in an empty area, then lift your finger.

If the assigned app opens, you are ready. Try assigning another app to a different gesture next.

Links at the top of the assignment screen jump to its five categories. The circular ? button at the top right opens scrollable instructions. Remove assignment clears a binding.

Try double taps and tap-and-hold gestures

Both begin with one short tap and release. Use one finger for two successive contacts; this is different from putting two fingers down together.

  1. In Double taps, assign an app to the same-position gesture.
  2. Return Home and tap the same position twice in quick succession, releasing after each tap.
  3. Assign a different app to the same-position Tap and hold gesture.
  4. Tap once and release, then immediately press and hold the same position. The action runs when the hold is recognized.

Right, left, up and down describe where the second contact lands relative to the first. For Right, tap once, release, then tap a point to its right. Do not keep the finger down and swipe.

Assigning a double tap or tap-and-hold gesture makes regular single taps wait briefly for a possible second contact. Assigning only pinch gestures does not add this delay.

Try two or three fingers

First assign an app to Pinch out (horizontal) under Pinch / two fingers. On Home, place two fingers side by side, move them apart, then lift either finger. Once the app opens, try the other motions below.

These are illustrations. Circles show starting contacts; arrows show movement.

Two-finger gestures

  • Pinch in/out: move closer for in, apart for out. Starting alignment selects right-hand diagonal (bottom-left ↔ top-right), left-hand diagonal (top-left ↔ bottom-right), horizontal or vertical. Each has separate in/out assignments.
  • Rotation: turn like a dial. Clockwise is right rotation; counterclockwise is left rotation. Any starting alignment works.
  • Parallel swipes: move both fingers together in the same diagonal direction without greatly changing their separation. The four directions are down-right, up-left, down-left and up-right.

Three-finger gestures

Use the Three fingers category to assign pinch in, pinch out, clockwise rotation and counterclockwise rotation separately. Bring the contacts closer for in, spread them outward for out, or turn them like a dial.

Pinch out also accepts the two upper fingers moving diagonally outward in parallel while the lower finger moves down. Rotation can work when two fingers turn sufficiently and the third makes a shorter movement or stays almost still.

For two or three fingers: touch → move clearly → lift any one of the participating fingers. The action runs once. Releasing the remaining fingers does not run it again.

If a gesture does not run

  • Check that gestures are enabled and an action is assigned to the exact gesture you are trying. Unassigned gestures do not run.
  • Start in an empty area and make a clear, reasonably large movement following the guide. Tiny contact drift is ignored.
  • For three-finger pinch out, move all three contacts outward. Sliding all three together in one direction is not pinch out.
  • Launching an app does not require the accessibility service. Enable it only for assignments using system controls such as opening notifications.
  • Gestures can also start over Home icons and buttons. Frequent-app scrolling and active dragging of sharing buttons have additional rules, so practice in an empty area first.

4. Search the text you entered

  1. Type a query such as weekend weather.
  2. Tap the top search button. The initial default opens Google Search.
  3. Return and try another query.
Illustrative example

C:\HOME> weekend weather

Search button → Google Search

You can now send the input to your search destination regardless of suggestions.

For ordinary text with no matching suggestions, explicit Enter also searches. If suggestions match, Enter runs the selected suggestion. Japanese composition confirmation alone does not search. Use the search button when unsure.

5. Register a destination and share text/images

Register the destination before entering the content you want to send.

  1. Long-press the top search/post button → Add sharing destination.
  2. Use Add at the bottom-right of management and choose a sharing app you use.
  3. Return Home and enter the text to send.
  4. Long-press the search/post button and select your destination.
  5. To include an image, enter text, then use + to choose an image, file or camera attachment before sending to the same destination.

You can now share text and images directly to a registered app.

Show share button adds a dedicated button to Home. Set as default changes the main button’s tap action. Receiving apps support different formats; test text alone and then one image first.
