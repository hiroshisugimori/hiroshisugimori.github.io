Get Started

Try five actions and start using CUIL right away.

Open CUIL first. Set it as the default Home app in Android settings if you want Home to return to it. Examples assume no conflicting custom commands.

1. Launch an app by name

Try the name of an app installed on your device.

  1. Tap CUIL’s input field.
  2. Type part of a name, such as Chrome if it is installed.
  3. Tap the app suggestion. Enter can also run the selected suggestion.
Illustrative example

C:\HOME> chr▌

Chrome → tap to launch

You can now launch an app from part of its name.

If nothing matches, check the actual app name and whether it is installed.

More about app search →

2. Register a short command

Give a frequently used app a short name you can remember. This example uses web.

  1. Open the top-right menu → Register command, or run regist.
  2. Enter web as the command name.
  3. In Apps, find and tap your browser. Tapping the target completes a new registration.
  4. Return to Home, type web and run the registered suggestion.

You can now launch an app with your own short name.

Run command to edit or delete a registration through its row menu. Save confirms edits. Commands can also target shortcuts and actions.

Tags, argument sharing and groups →

3. Assign a gesture

Start by assigning an app to Circle.

  1. Open the top-right menu → Settings → Gestures.
  2. Enable gestures if needed, then open Gesture assignments.
  3. Check the Circle drawing guide, choose Register in that row, and select an app.
  4. Return Home, draw one continuous circle starting in an empty area, and lift your finger.

You can now launch an app by drawing a circle.

Launching an app this way does not require the accessibility service. Only assignments for system controls such as opening notifications need it. Start in an empty area at first, since frequently used apps also have scrolling rules.

4. Search the text you entered

  1. Type a query such as weekend weather.
  2. Tap the top search button. The initial default opens Google Search.
  3. Return and try another query.
Illustrative example

C:\HOME> weekend weather

Search button → Google Search

You can now send the input to your search destination regardless of suggestions.

For ordinary text with no matching suggestions, explicit Enter also searches. If suggestions match, Enter runs the selected suggestion. Japanese composition confirmation alone does not search. Use the search button when unsure.

Defaults, Enter and direct URLs →

5. Register a destination and share text/images

Register the destination before entering the content you want to send.

  1. Long-press the top search/post button → Add sharing destination.
  2. Use Add at the bottom-right of management and choose a sharing app you use.
  3. Return Home and enter the text to send.
  4. Long-press the search/post button and select your destination.
  5. To include an image, enter text, then use + to choose an image, file or camera attachment before sending to the same destination.

You can now share text and images directly to a registered app.

Show share button adds a dedicated button to Home. Set as default changes the main button’s tap action. Receiving apps support different formats; test text alone and then one image first.
