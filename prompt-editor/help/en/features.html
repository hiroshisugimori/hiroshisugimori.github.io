Editing and input

Type in the editor. Tap the title to rename the draft. Use the microphone for speech input when a compatible speech recognition app is available. Images and phrases are inserted at the cursor; tapping blank editor space moves the cursor to the end.

Markdown

Use headings (#), bold (**text**), emphasis, bullet and numbered lists, quotes (>), links, inline code, and fenced code blocks. The editor keeps the source notation. Preview, PDF, PNG, and HTML render formatting; text sharing and prompt.txt in ZIP retain the source.

Images, videos, and file attachments

The image menu offers gallery, camera, file selection, and creation of a blank image. A new image is a white square and opens in the drawing editor. Images and videos appear in the document; other files appear in the attachment list. Image deletion asks for confirmation; remove other files with their attachment-list buttons.

Cropping and sharing one image

Tap an image to open its enlarged preview, then crop to the area you want. A cropped image offers a restore action. The export button beside crop shares only this image as a PNG, including drawing and orientation corrections. This is separate from sharing the whole document.

Drawing and mosaic

Open the brush button in enlarged image preview. Adjust pencil color and width or eraser width. Add text, adjust its color, size, and position, then confirm. For mosaic, drag a rectangle, drag inside to move it, use its eight handles to resize, adjust strength, and confirm. Pan/zoom, fit-to-view, undo/redo, and reset are available. Save your edits before leaving.

Preview and output layout

Open the eye icon left of the microphone, or Preview in the editor menu. Pinch an image to resize it while keeping its aspect ratio. Long-press to move one image beside another image or text; images in a row remain individually movable. Text wraps in the remaining width beside an image. Drops near the left and right edges are easier even beside a single line. Drop on the header to move an image to the document start. Alignment, separate-row placement, help, and reset with confirmation are available. Images can also go between text sections separated by blank lines or Markdown headings. Layout and size changes apply to PDF, PNG, and HTML, and do not reorder the editor document. Text output and prompt.txt in ZIP do not include layout information.

Output formats

Choose a format from Share at the bottom or Share (export) in the editor menu. PDF is selected initially for images; ZIP is selected for videos or other file attachments. See the table below for capabilities and restrictions. A progress dialog appears while ZIP is being created.

Output format comparison
FormatContent and restrictions
TEXTSource text. Image references are text; image files are not included.
PDFText and images in one PDF. Unavailable with videos or general file attachments.
PNGText, images, and video thumbnails in one image. Videos do not play. Unavailable with general file attachments.
HTMLFormatted HTML with embedded images. Unavailable with videos or general file attachments.
ZIPBundles prompt.txt and images, videos, or other attachments. Text keeps Markdown source; exported images include crops and drawings.

Share Selector and sharing

Add or remove destinations in Settings → Share Selector, or open it from the sharing dialog. Use Add and search app names to register a destination. The dialog is shown even with no registered destinations; choose All apps to use Android sharing. Selecting a registered destination opens that app, with fallback when it cannot be opened. Choose the final save location in the receiving app. Android sharing alone does not automatically save a file to your PC.

Receiving shares from other apps

Select prompt editor in another app’s share sheet to create a new draft from text, images, videos, or files. Multiple files and mixed text/media are supported. The current draft is saved before importing.

Drafts and autosave

Create a draft with + and reopen it from Drafts. Changes are saved automatically. Each card’s three-dot menu offers duplication, tags, title editing, and deletion. Duplicates include their own attachment and drawing copies. Long-press to select multiple drafts, use checkboxes, then tap the trash button for a count-based confirmation. Close or Back exits selection. Deleting every draft leaves a new blank draft. Dates less than a year old omit the year; older dates include it.

Search and tags

Use the magnifying glass in Drafts. Space-separated terms must all match somewhere in the title, body, or tags; matching is partial and case-insensitive. Selecting an existing tag applies it immediately; removing an assigned tag with × is also immediate. Save adds the typed new tag. Cancel does not undo those immediate changes. Tags appear with # in the list and are excluded from exported content.

Phrases and shortcuts

Create, edit, or delete phrases in the phrase list. Assign them to the six editor slots and tap to insert at the cursor; an empty slot can create a phrase. Long-press menus offer Share, Copy, and Edit so you can reuse a phrase without inserting it. Sharing and slot assignment are also available from the list.

Placeholders

Use fields such as {{name}}, {{count:number}}, or {{reference:image}} inside phrases, or insert them with the placeholder button in phrase editing. Fill in text, numbers, or images when using the phrase. Repeated names share an input, and malformed syntax or conflicting types is validated.

Copy and clear

Copy all copies document text to the clipboard. Use Share for image files. Clear in the editor menu asks for confirmation, then removes text and attachments from the current draft.

Google Drive backup

Back up or restore phrases to Google Drive from Settings, granting Google authorization when asked. Restore asks for confirmation and replaces local phrases and shortcut assignments. This backs up phrases and the six shortcut assignments, not drafts or their attachments.

Settings, ads, and release history

Settings offers a one-time ad-removal license; check the displayed Google Play price and purchase flow. Settings also shows the version, release history, and help. After an update, up to three applicable release entries can appear at startup; Settings shows all entries. Japanese locales use Japanese, and other languages use English.

This guide describes the current source. Screens and features may differ in the version installed on your device.
