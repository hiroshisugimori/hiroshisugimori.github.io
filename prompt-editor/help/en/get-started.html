1. Add an image

Use the image button to choose Gallery or Camera. Choose Create new image to draw on a white canvas. The image is inserted at the cursor.

Detailed instructions →

2. Crop the image

Tap the image, then use the crop icon to keep the part you need.

Detailed instructions →

3. Annotate with drawing tools

Open the brush icon to add lines, text, or mosaic. Confirm text or mosaic edits, then save.

Detailed instructions →

4. Write the instructions

Describe what the agent should do with the image. Markdown headings, lists, and bold text can separate the subject from the task.

Detailed instructions →

5. Check the preview

Open the eye icon, pinch images to resize, and long-press to move them beside text or other images. These layout adjustments apply to output.

Detailed instructions →

6. Set up Share Selector

Register your preferred saving or transfer apps in Settings → Share Selector. You can also choose All apps while sharing without registration.

Detailed instructions →

7. Choose a format and share

Choose PDF, PNG, HTML, ZIP, or text from Share. Configure the PC transfer or save location in the receiving app. PDF or PNG combines text and images; ZIP bundles the source text and attachments.

Detailed instructions →

8. Give the file to your AI agent

Pass the saved file path to your AI agent. The agent must have access to local files and support the selected format. In chats without local file access, attach the file to the chat instead.

Detailed instructions →

Example instructions

## Requested changes
- Move the marked button in the attached image to the right.
- Verify the resulting behavior.

Saving to a PC and using file paths

Complete the transfer using the receiving app first. If the result is saved in the PC Downloads folder, you can ask:

C:\Users\your-name\Downloads\instructions.pdf
Read the newest file in my Downloads folder and implement the instructions.

If other downloads may intervene, specify the exact filename or full path. For ZIP, ask the agent to inspect prompt.txt and the attachments. Rendering can differ between browser HTML and PDF/PNG, so inspect the exported result too.

This guide describes the current source. Screens and features may differ in the version installed on your device.
