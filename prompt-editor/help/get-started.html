Get Started — 画像付きの指示をAIへ

対象実装: 0.35.0 / versionCode 36 · 最終確認: 2026-11-03

ヘルプトップGet Started全機能紹介

このページは模式図と操作例です。AIの回答を生成する機能はなく、出力した指示をAIに渡して利用します。

  1. 画像を貼る
  2. 画像をトリミングする
  3. お絵描きツールで加工する
  4. テキストで指示を書く
  5. プレビューで見た目を確認する
  6. Share Selectorで共有先を設定する
  7. 形式を選んで共有・保存する
  8. エージェントAIにファイルを渡す

1. 画像を貼る

画像挿入ボタンからギャラリーまたはカメラを選びます。白紙から描くなら新規画像作成を使います。画像はカーソル位置へ入ります。

詳しい操作 →

2. 画像をトリミングする

画像をタップして拡大し、トリミングアイコンで必要な部分だけ残します。

詳しい操作 →

3. お絵描きツールで加工する

筆アイコンから、線・文字・モザイクを加えます。モザイクや文字は確定し、最後に保存します。

詳しい操作 →

4. テキストで指示を書く

画像について何をしてほしいかを書きます。Markdownの見出し・箇条書き・太字などで、対象と依頼を分けると読みやすくなります。

詳しい操作 →

5. プレビューで見た目を確認する

目のアイコンで開き、画像をピンチしてサイズ変更、長押しして移動します。画像やテキストの横に置けます。配置調整は出力用です。

詳しい操作 →

6. Share Selectorで共有先を設定する

設定のShare Selectorでよく使う保存・転送アプリを登録します。登録なしでも共有時に全てのアプリを選べます。

詳しい操作 →

7. 形式を選んで共有・保存する

共有からPDF・PNG・HTML・ZIP・テキストを選びます。共有先でPCへの転送や保存先を設定してください。文章と画像を1つにするならPDFやPNG、原文と添付をまとめるならZIPが便利です。

詳しい操作 →

8. エージェントAIにファイルを渡す

PCへ保存したファイルのパスをエージェントAIへ渡します。AIがローカルファイルにアクセスでき、選んだ形式を読める環境が必要です。ファイルを参照できないチャットでは、そのチャットへの添付を使ってください。

詳しい操作 →

指示の例

## 修正依頼
- 添付画像の印を付けたボタンを右へ移動してください。
- 変更後の動作を確認してください。

PCへの保存とファイルパス

共有先アプリで、PCへの転送を済ませてから依頼します。PCのダウンロードフォルダに保存した場合は、次のように伝えられます。

C:\Users\your-name\Downloads\instructions.pdf
ダウンロードフォルダの一番新しいファイルを見て実装してください。

別のダウンロードが混じる場合は、ファイル名やフルパスを指定する方が確実です。ZIPを渡すときは中のprompt.txtと添付も確認するよう伝えます。ブラウザで読むHTMLとPDF・PNGでは見え方が異なることがあるため、出力結果も確認してください。

現在のソースコードに基づく説明です。インストールしている版によって画面や機能が異なる場合があります。
